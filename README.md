# Алгоритмические и языковые упражнения

**Python · C++ · Pascal · Refal · Assembly · CLIPS**

Тематическая подборка программ: алгоритмические задачи, обходы графов, сортировки, рекурсия, функциональные и логические языки, небольшие игровые приложения.

Папки сгруппированы по языкам и темам. Каждая программа запускается или собирается отдельно; параметры ввода определяются её условием и точкой входа.

```bash
python3 python/factorization.py
python3 python/graph_traversal.py
```

Для факторизации подаётся положительное целое число; например, 84 даёт 2 2 3 7. Графовый пример демонстрирует множество достижимых вершин. Игровые программы требуют соответствующих ресурсов и библиотек, перечисленных в их импортах.

Для примеров интеграции с VK API используется переменная окружения `VK_API_TOKEN`; параметры подключения настраиваются перед запуском. Refal и CLIPS запускаются соответствующими интерпретаторами; ассемблерные примеры требуют подходящей разрядности и учебных include-файлов.
