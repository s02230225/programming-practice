# Численное интегрирование

Учебная работа по численным методам, 2024 год. Егор Пугачев, группа 215 ВМК МГУ.

Исследуется интеграл функции `ln(x + 2) / sqrt(3*x - x**2)` на отрезках `[1, 2]`
и `[0, 3]`. Реализованы составные формулы трапеций и Симпсона, рассмотрена обработка
особенностей на концах второго отрезка. Для сеток из 16, 32 и 64 частей строятся
графики аппроксимации и сравниваются результаты со `scipy.integrate.quad`.
Для визуализации метода Симпсона используется квадратичная интерполяция Лагранжа.

```bash
python3 -m pip install -r requirements.txt
jupyter notebook integration.ipynb
```

В подборке представлен один оформленный вариант работы; результаты получаются
при последовательном выполнении ячеек ноутбука.
